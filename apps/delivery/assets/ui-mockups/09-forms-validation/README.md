# Foundation 09 — Forms and validation

[Forms and validation board](01-forms-validation.png)

One Storybook-style Flutter iOS/Android reference generated with built-in image generation. Brand primary: burnt orange `#C2410C`. Includes light/dark form specimens and single-border focus.

Covers persistent labels, required/optional fields, email/password, Indian phone/address/PIN, vehicle-dependent fields, bank/UPI details, inline errors, loading and retained input on failure. All entered data is illustrative. Asterisks mean required. Payout details are optional during signup; partial bank details must still be validated, and later changes follow admin review. Read-only and disabled are distinct semantic states in implementation even when similarly muted in the board. Retained input refers to in-session recovery, not unrestricted storage of passwords or financial fields. Validate with existing server contracts; this raster does not verify runtime behaviour.
