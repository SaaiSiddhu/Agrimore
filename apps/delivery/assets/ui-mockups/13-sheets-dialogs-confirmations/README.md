# Foundation 13 — Sheets, dialogs and confirmations

[Sheets, dialogs and confirmations board](01-sheets-dialogs-confirmations.png)

One Storybook-style Flutter iOS/Android reference generated with built-in image generation. Brand primary burnt orange `#C2410C`, light/dark examples, Lucide-style icons.

Covers action sheets, seller-not-ready release before pickup, distant-location confirmation, sign-out, unsaved edits, allowed/blocked account deletion and emergency help. Photo-source choices and unsaved-change handling are component concepts subject to actual integration. The 450 m distance is illustrative, not a hard geofence. Release returns the order for reassignment; it does not cancel the customer's order. Account deletion respects assigned-order, held-cash and unpaid-balance checks. Emergency dialling and reporting require separate explicit actions; a recorded report is not evidence of human review. Implement native focus, dismissal, safe areas and keyboard behaviour and verify them on devices.
