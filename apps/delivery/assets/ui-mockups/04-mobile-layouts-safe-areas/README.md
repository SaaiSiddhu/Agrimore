# Foundation 04 — Mobile layouts and safe areas

[Mobile layouts and safe areas](01-mobile-layouts-safe-areas.png)

One Storybook-style board generated using built-in image generation for native Flutter iOS/Android. Primary burnt orange `#C2410C`. Covers small/large phones, device safe areas, keyboard-visible forms, scrolling and sticky actions, bottom sheets and enlarged text.

Design reference only: annotations specify logical layout intentions, not measured raster geometry or verified device behaviour. Insets must follow each device and keyboard. Large text must grow and reflow; actions must remain reachable. Preserve one existing focus border. Product illustrations are content thumbnails, not interface icons. The palette footer's generated section number is decorative, not a phase identifier.
