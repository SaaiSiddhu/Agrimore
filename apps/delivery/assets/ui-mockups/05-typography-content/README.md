# Foundation 05 — Typography and content

[Typography and content board](01-typography-content.png)

One Storybook-style mobile UI reference for Flutter iOS/Android, generated with built-in image generation. Primary burnt orange `#C2410C`, warm neutral documentation text, and light/dark specimens.

Covers heading hierarchy, readable addresses, six-digit delivery-code input, amounts, distance, estimated ETA, timestamps, instructions, concise errors and enlarged text.

All names, amounts, addresses, entered digits and timestamps are illustrative. COD and prepaid rows demonstrate alternative payment states, not simultaneous obligations. Delivery code is customer-provided rider input, not a secret revealed by the app. Numeric type specifications express intended logical sizes; raster specimens are not measurement or contrast verification. Production text must scale and use localization.
