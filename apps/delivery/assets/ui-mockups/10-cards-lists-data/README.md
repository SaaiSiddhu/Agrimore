# Foundation 10 — Cards, lists and data presentation

[Cards, lists and data board](01-cards-lists-data.png)

One Storybook-style reference for native Flutter iOS/Android, generated with built-in image generation. Brand primary: burnt orange `#C2410C`. Light/dark examples with Lucide-style icons.

Covers offer and active-task cards, history rows and existing combined cancelled/returned filter, earnings, weekly statements, document status, pagination, incremental loading/failure, end-of-list and empty states.

Illustrative arithmetic: delivery pay 30 + 12 + 6 = 48; pending statement 1200 - 580 = 620; paid statement 980 - 360 = 620. COD cash is separate from rider earnings. Figures are examples, not compensation rates or live records. Photo added is not document approval. Statement ready is not paid. Retain loaded rows on subsequent-page failure. Actual page sizes and permitted actions follow source contracts. Mockups do not verify runtime interactions.
