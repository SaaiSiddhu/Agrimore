# Foundation 03 — Themes and appearance

[Themes and appearance board](01-themes-appearance.png)

One Storybook-style image for Flutter iOS/Android, generated with built-in image generation. Primary burnt orange `#C2410C`; light background `#FFFAF5`; dark background `#171210`; dark surface `#251C17`; dark accent `#FDBA74`.

Covers matching light/dark active-delivery map and card examples, system appearance, surfaces, forms and single-border focus, overlays, disabled states and outdoor legibility.

The manual Light/Dark/System preference is a proposed UI; current app follows system appearance. Day/night thumbnails illustrate device appearance changes, not a new scheduled switching feature. Disabled specimens show enabled controls above disabled controls for comparison. Contrast, touch targets and platform behaviour require implementation-time verification. Sample addresses are illustrative.
