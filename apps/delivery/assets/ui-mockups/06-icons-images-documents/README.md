# Foundation 06 — Icons, images and documents

[Icons, images and documents board](01-icons-images-documents.png)

One Storybook-style reference for Flutter iOS/Android, generated with built-in image generation. Brand primary: burnt orange `#C2410C`.

Covers Lucide-style icons and sizes, rider avatar and fallbacks, custom vehicle symbols, merchant imagery, document upload thumbnails, optional delivery proof photos, and loading/missing/failed image states, with light/dark specimens.

Portraits, shops and proof photos are generated illustrative content. Document previews are generic SAMPLE placeholders. Photo added does not mean approved. A delivery remains complete if its optional proof photo fails to save. Runtime icons must use verified Flutter-compatible Lucide exports; custom vehicle symbols require matching artwork. Dimensions are design intentions, not measurements of this raster board.
