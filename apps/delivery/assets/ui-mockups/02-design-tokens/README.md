# Foundation 02 — Design tokens

[Design tokens board](01-design-tokens.png)

One Storybook-style reference covering semantic colours, spacing, corner radii, borders/focus, elevation, Lucide-style icon sizes, touch targets, component sizing and applied light/dark mobile examples. Flutter iOS/Android. Primary: burnt orange `#C2410C`. Built-in image generation; visual concept, not runtime UI or measured accessibility verification.

Implementation interpretation: use 16 for card radii and 12 for control radii; the applied card's generated 12-radius annotation is an illustration inconsistency. Numeric tokens govern implementation rather than measured raster dimensions. Focus strengthens the existing border without a second ring.
