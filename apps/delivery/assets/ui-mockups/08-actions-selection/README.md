# Foundation 08 — Actions and selection

[Actions and selection board](01-actions-selection.png)

One Storybook-style Flutter iOS/Android reference generated with built-in image generation. Primary burnt orange `#C2410C`; light/dark variants.

Covers button hierarchy, interaction states, online/offline/pending toggle, history filters, chips, radio/checkbox/list selections, loading actions, submission confirmation and failure recovery.

Focus specimen demonstrates a single strengthened existing outline on an outlined button; it does not prescribe converting a filled primary button to an outlined variant on focus. Preserve each component's style and geometry. Dashed chip boxes indicate touch-area measurement, not focus decoration. Removable filter is a proposed component concept. Delete-account actions remain subject to account/balance blockers. Online success follows readiness checks. Recorded report does not mean human review. Duplicate-request prevention and safe retry behaviour require real implementation and tests.
