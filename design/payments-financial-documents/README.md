# Foundation 19 — Payments and financial documents

Seven separate final Storybook-style concept boards for Flutter iOS/Android. Generated one by one with built-in image_gen and visually reviewed. Raster Lucide-style icons are visual references, not React components or implemented Flutter screens. The surrounding Storybook shell is documentation only.

Palette: primary #0F766E, mint #DDF3EA, black #050908, dark surface #0B1513, dark accent #5EEAD4.

No wallet, withdrawal, payout request, or seller payment approval controls. Board 7 demonstrates the payments overview and empty state within that scope.

Illustrative amounts: order 1042 ₹580 − ₹29 = ₹551 pending; order 1041 ₹320 − ₹16 = ₹304 paid. September totals ₹900 − ₹45 = ₹855, split ₹304 paid and ₹551 pending. Dates are example recorded events, not settlement promises. Bank details are masked, payment reference is a placeholder, and tax-invoice fields intentionally use placeholders.

Source context: seller-mockup-research.md; apps/seller/lib/screens/payments/payments_screen.dart and statements.dart; apps/seller/lib/screens/orders/invoice_screen.dart. UPI masking, copy-reference affordances, empty-month treatment and some navigation details are design proposals rather than claims about current implementation. Financial values are sample data, not tax or financial guidance.
