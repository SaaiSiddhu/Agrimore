## Design intent and validation

These are visual design targets, not an accessibility audit or implemented behaviour. Icons are Lucide-style raster illustrations, not actual React or Flutter components. Phone frames, focus outlines and annotations are conceptual; platform controls and assistive-technology wording vary. Test actual Flutter screens with external keyboards, VoiceOver, TalkBack, system text scaling and motion preferences.

The shared touch target is at least 48 × 48 Flutter logical pixels. Contrast annotations are thresholds to test in implementation, not measured pass results for the generated images. Normal text targets 4.5:1, qualifying large text 3:1, and meaningful non-text control indicators 3:1 against adjacent colours. Preserve focus visibility, logical traversal, persistent form labels, non-colour cues and usable reflow. Reduced-motion designs show static progress and completion feedback. Chart examples use illustrative counts Mon 4, Tue 6, Wed 2, total 12, repeated in the data table. Error focus movement happens after submission; routine background status announcements should preserve the user’s place.
