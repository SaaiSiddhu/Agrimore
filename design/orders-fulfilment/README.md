# Foundation 17 — Orders and fulfilment

Seven separate visual concept boards, one per requested group, generated sequentially with built-in image_gen. Flutter native iOS/Android only. Lucide-style raster representations, not React components or tested Flutter screens. Each board includes related variants. Values are illustrative; tax invoice uses placeholders. Cancellation eligibility and contact-channel implementation require validation against product rules.

Palette: #0F766E primary, #DDF3EA mint, #050908 black, #0B1513 dark surface, #5EEAD4 dark accent.
