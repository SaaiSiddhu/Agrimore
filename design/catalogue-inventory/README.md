# Foundation 18 — Catalogue and inventory

Eight separate final Storybook-style UI/UX concept boards for Flutter iOS/Android. Generated sequentially using built-in image_gen; boards 1 and 2 recovered from the previous task, with board 2 corrected here. Each board contains related mobile states. These are raster mockups with Lucide-style icon representations, not React components or implemented Flutter screens. The surrounding Storybook shell is documentation, not desktop product UI.

Palette: primary #0F766E; mint #DDF3EA; black #050908; dark surface #0B1513; dark accent #5EEAD4.

Values are illustrative. Navigation grouping is proposed. Source context: seller-mockup-research.md, seller add_product_screen.dart, product_variants_section.dart and product_tax_section.dart. Tax fields show no assigned product classification. Final boards were visually inspected; generated images are concept references, not pixel-exact component specifications.
