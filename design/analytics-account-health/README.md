Account-health sample uses a separate 30-day activity window: 100 orders, 72 delivered, 8 cancelled; fulfilment 90%, cancellations 8%, rating 4.5, listings 75%, quote responsiveness 80%. Normalized contributions 94.7368,80,100,93.75,88.8889 average to 91.4751, rounded score 91. Good >=80, Needs attention 60–79, At risk <60. Insufficient data is not zero. Current app logic checks photo, description, HSN and GST presence for listing completeness; this is not tax guidance.

Sources inspected: apps/seller/lib/screens/insights/insights_rules.dart, insights_screen.dart, health_screen.dart, home/dashboard_screen.dart and seller English localizations.
