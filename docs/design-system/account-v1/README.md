Implementation notes:
- Reuse the canonical floating navigation; actual Lucide outline icons including active Profile, despite generated filled glyphs.
- Keep labels sharp, clip blur behind navigation, allow sufficient scroll bottom padding, and support reduced transparency.
- Profile sample email uses reserved example.com. Handle missing email for phone-only associates; do not fabricate it.

- Profile remains selected because these examples open from Profile. If notifications open from Home, preserve that originating navigation context.
