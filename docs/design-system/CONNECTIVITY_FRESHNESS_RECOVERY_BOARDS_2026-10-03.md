[Codebase and domain map](CONNECTIVITY_FRESHNESS_RECOVERY_DOMAIN_MAP_2026-10-03.md) · [C01 approval index](COLOR_ROLES_THEME_IDENTITY_LOCK_2026-10-02.md).

Five domain recovery systems distinguish read availability, cached or unverified data, read refresh and supported operation recovery. Marketplace checkout, Seller stock, Delivery proof, Associate payout and Admin order action each have different recovery prerequisites. Cached records do not prove offline; available internet does not prove current data. An unknown server action may already have finished. No generic offline payment queue, autosync or automatic action replay is proposed. These are design specimens, not running app screenshots or implemented recovery widgets. Exact C01 token metadata is inherited; raster colors and geometry are approximate. Empty rows deliberately omit record values. No sidebar.
