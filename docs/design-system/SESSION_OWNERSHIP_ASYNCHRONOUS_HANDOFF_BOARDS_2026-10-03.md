# Agrimore — C19 session ownership and asynchronous handoff

**PROVISIONAL_DIRECTION / TARGET_IMPLEMENTATION · v1 · 2026-10-03.** Ten premium Storybook boards: one light and one dark per app. C01 remains the approved identity reference.

[Codebase and domain map](SESSION_OWNERSHIP_ASYNCHRONOUS_HANDOFF_DOMAIN_MAP_2026-10-03.md) · [C01 approval index](COLOR_ROLES_THEME_IDENTITY_LOCK_2026-10-02.md).

Five domain handoff systems distinguish account transition, confirmed sign-in requirement, ignored late UI results and current-account recovery. Shopper checkout, merchant stock, rider tasks, associate payout review and admin case actions have different outcomes and recovery boundaries. A discarded UI response does not cancel server work or prove a mutation failed. Checking access keeps old sensitive content hidden; sign-in is requested only for actual session loss, not every read failure. These generated boards are target design specimens, not implemented widgets or running app screenshots. Exact C01 token metadata is inherited; raster colors and geometry are approximate. Empty skeletons deliberately omit record values. Diagrams describe UI boundaries and are not old-account notifications. No sidebar.
