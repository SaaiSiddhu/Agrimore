# Agrimore — C06 mobile layout, safe areas and keyboard

**PROVISIONAL_DIRECTION / TARGET_IMPLEMENTATION · v1 · 2026-10-03.** Ten Storybook boards, five app identities, two themes each. Approved C01 identity remains locked. These static proposals do not change app runtime or register bundled assets.

[Codebase and domain mapping](MOBILE_LAYOUT_SAFE_AREAS_KEYBOARD_DOMAIN_MAP_2026-10-03.md) · [Locked five-app identity](COLOR_ROLES_THEME_IDENTITY_LOCK_2026-10-02.md).

The keyboard-open diagrams reserve a shorter scrolling body and place the action above the keyboard. Safe-area and keyboard heights are system measured; board drawings are illustrative. Light/dark pairs share one app-specific layout contract.
